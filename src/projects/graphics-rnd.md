## Non-photorealistic shaders

Cel shading, cross-hatching and other stylized shaders built with Python-generated and hand-drawn textures, in WebGL and Three.js.

## Cloth simulation

A real-time cloth simulation in C++ and OpenGL using a mass-spring system, with self-collision, collision with other objects, and custom diffuse, Blinn-Phong and texture-mapped shaders.

## Painterly rendering

A Python implementation of painterly rendering from photographs using layers of spline brush strokes, based on Aaron Hertzmann's SIGGRAPH 1998 paper.
